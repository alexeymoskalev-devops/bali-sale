# Bali Sale

Лендинг распродажи личных вещей перед отъездом (Чангу, Бали). Собран из дизайна
Claude Design (`design/Bali Sale.dc.html`) в чистую статику без зависимостей и сборки.

## Запуск

```bash
# просто открыть в браузере
open index.html

# или локальный сервер
python3 -m http.server 8000
```

## Структура

```
sale/
├── index.html   # каркас страницы + модалка
├── styles.css   # все стили (дизайн-токены в :root)
├── app.js       # данные товаров (ITEMS/DETAILS/T) + рендер + события
├── images/      # оптимизированные фото (1280px, jpeg q65)
└── design/      # исходный экспорт из Claude Design (референс, на сайт не влияет)
```

## Как редактировать товары

Всё в `app.js`:

- **`ITEMS`** — карточки: `id`, категория/название/состояние/заметка в парах `[ru, en]`,
  `price` (IDR), `photos` (имена файлов из `images/` без расширения).
- **`DETAILS`** — абзацы модалки по `id`: `[[ru...], [en...]]`.
- **Пометить проданным:** добавить `sold: true` в объект товара.
- **Добавить фото:** положить `images/<name>.jpg` и вписать `<name>` в `photos`.

Контакт для кнопок — константа `TG_USER` (`alex_xmos`).
